# results/

Everything in this directory except this file is ignored by git and regenerated by the
scripts in `scripts/`. Final result tables (CSV) and plots (PNG) are force-added once the
week 3 experiments are frozen.

Layout: `results/<sequence>/` holds `gt.tum`, `identity.tum`, `gt_lidar_frame.tum`,
estimated trajectories `est_*.tum`, and evo outputs (`ape_*.png`, `ape_*.zip`, `rpe_*.zip`).

## Evaluation protocol (fixed before any odometry exists)

- Sequences: exp14 (A, tuning), exp18 (B, held out), exp16 (C, held out). These are the three
  Hilti-Oxford 2022 sequences with dense 6-DoF ground truth (`*_imu.txt`, 10 Hz, frame I).
  B and C are run once with parameters frozen after tuning on A.
- Metrics: ATE and RPE (1 m delta) via `evo_ape` / `evo_rpe` with SE(3) Umeyama alignment,
  exactly the flags in `scripts/eval.sh`; percentage of the sequence with a valid pose;
  scans per second (offline processing time, not playback); peak RSS.
- Ablations: deskewing off; IMU-propagated initial guess off. This is the LiDAR-IMU evidence.
- Frames: every estimate is transformed into the IMU frame `I` (`T_W_I = T_W_L * T_I_L^-1`,
  docs/01) before evo runs. Week-1 measurement on exp14: leaving the ground truth in the LiDAR
  frame changes the aligned ATE by only 8.7 mm RMSE but the 1 m RPE by 1.58 m RMSE, because
  RPE is expressed in the body frame and is not invariant to a right-multiplied extrinsic.

## Week 1 checks (exp14, 2026-09-11)

| Check | Command | Result |
|---|---|---|
| Identity trajectory vs ground truth, unaligned | `ALIGN=0 scripts/eval.sh results/exp14 results/exp14/identity.tum identity` | ATE RMSE 113.95 m (ground truth sits about 120 m from the survey-scanner origin); timestamps associate 1:1 |
| Ground truth in LiDAR frame vs ground truth, aligned | `scripts/eval.sh results/exp14 results/exp14/gt_lidar_frame.tum gt_lidar_frame` | ATE RMSE 8.7 mm, max 17.6 mm; RPE(1 m) RMSE 1.58 m (see Frames above) |
- All numbers come from offline, scan-by-scan processing on a 2-core laptop. Processing time is
  reported as such and is not a real-time claim.
- Recorded dataset evaluation is not a physical deployment and is described as such in the report.
