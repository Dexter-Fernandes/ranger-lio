# 01: SO(3) and SE(3)

## Purpose

Everything downstream perturbs, composes and differentiates rigid transforms: gyro
integration (doc 02) integrates on $SO(3)$, registration (doc 03) needs the Jacobian of a
transformed point with respect to a pose perturbation, and the pose graph (doc 05) needs
$\mathrm{Log}$ of a relative pose and the adjoint to move covariances between frames. This
document derives the closed forms and fixes the small-angle and near-$\pi$ handling the
implementation must have. Conventions are those of doc 00: right perturbations, tangent
vectors ordered $(\theta, \rho)$.

## Derivation

### Skew-symmetric matrices

For $a \in \mathbb{R}^3$ define $[a]_\times$ so that $[a]_\times b = a \times b$:

```math
[a]_\times = \begin{bmatrix} 0 & -a_3 & a_2 \\ a_3 & 0 & -a_1 \\ -a_2 & a_1 & 0 \end{bmatrix},
\qquad
[a]_\times^\top = -[a]_\times, \qquad
[a]_\times^2 = a a^\top - \|a\|^2 I, \qquad
[a]_\times^3 = -\|a\|^2 [a]_\times .
```

The inverse map is $\mathrm{vee}$: $\mathrm{vee}([a]_\times) = a$. For $R \in SO(3)$,
$[Ra]_\times = R [a]_\times R^\top$ (rotating the axis rotates the cross-product operator).

### Exponential map (Rodrigues)

A rotation of angle $\varphi = \|\theta\|$ about the unit axis $u = \theta/\varphi$ is the
solution at $s = 1$ of $\dot R(s) = R(s)[\theta]_\times$, $R(0) = I$, i.e. the matrix
exponential $\exp([\theta]_\times) = \sum_n [\theta]_\times^n / n!$. Using
$[\theta]_\times^3 = -\varphi^2[\theta]_\times$ the odd powers collapse onto $[\theta]_\times$
and the even powers onto $[\theta]_\times^2$:

```math
\mathrm{Exp}(\theta) = I + \frac{\sin\varphi}{\varphi}[\theta]_\times
  + \frac{1-\cos\varphi}{\varphi^2}[\theta]_\times^2 .
```

For $\varphi \to 0$ the coefficients are $1 - \varphi^2/6$ and $1/2 - \varphi^2/24$; below
$\varphi = 10^{-6}$ the implementation uses $I + [\theta]_\times + \tfrac12[\theta]_\times^2$
to avoid $0/0$.

### Logarithm

From Rodrigues, $\mathrm{tr}\,R = 1 + 2\cos\varphi$ and $R - R^\top = 2\sin\varphi\,[u]_\times$.
Both the cosine and the sine of the angle are therefore available, and the angle is recovered
with the well-conditioned two-argument arctangent:

```math
\cos\varphi = \frac{\mathrm{tr}\,R - 1}{2}, \qquad
\sin\varphi = \tfrac12\,\big\|\mathrm{vee}(R - R^\top)\big\|, \qquad
\varphi = \operatorname{atan2}(\sin\varphi, \cos\varphi), \qquad
\theta = \frac{\varphi}{2\sin\varphi}\,\mathrm{vee}(R - R^\top), \quad 0 < \varphi < \pi .
```

Using $\varphi = \arccos(\cos\varphi)$ alone is the textbook form and it is numerically wrong
near $\pi$: $d\varphi / d(\cos\varphi) = -1/\sin\varphi$, so a round-off error of order
$\epsilon \approx 10^{-16}$ in the trace becomes an angle error of order $10^{-16}/\sin\varphi$,
and at $\varphi = \pi - 10^{-4}$ that is amplified further by the arccos branch to about
$10^{-4}$ rad. This was found by the `ExpLogRoundTrip` near-$\pi$ test on the first
implementation (round-trip error $10^{-4}$ instead of $10^{-9}$) and is the reason the
derivation carries the atan2 form.

Two limits need care:

- **$\varphi \to 0$**: $\varphi / (2\sin\varphi) \to 1/2$, so
  $\theta = \tfrac12 \mathrm{vee}(R - R^\top)$. The argument of $\arccos$ is clamped to
  $[-1, 1]$ first, since round-off pushes it above 1 for the identity.
- **$\varphi \to \pi$**: $\sin\varphi \to 0$, and the axis $u = \mathrm{vee}(R - R^\top)/(2\sin\varphi)$
  has relative error $\epsilon/\sin\varphi$; it is still good to $10^{-11}$ at
  $\sin\varphi = 10^{-5}$, so the general formula is kept until then. Closer to $\pi$, split
  $R$ into its symmetric and antisymmetric parts,

  ```math
  R = \cos\varphi\, I + (1 - \cos\varphi)\, u u^\top + \sin\varphi\, [u]_\times ,
  \qquad
  \tfrac12 (R + R^\top) + I = (1 + \cos\varphi)\, I + (1 - \cos\varphi)\, u u^\top ,
  ```

  and take the column of the symmetric part with the largest norm, which is parallel to $u$
  up to $O(1 + \cos\varphi) = O((\pi - \varphi)^2)$. The sign of $u$ is fixed by requiring
  $u^\top \mathrm{vee}(R - R^\top) \ge 0$, which holds exactly when $\sin\varphi > 0$. At
  $\varphi = \pi$ exactly both signs are correct and either is accepted. The branch is
  selected by $\sin\varphi < 10^{-5}$ **and** $\cos\varphi < 0$: the sine alone is also small
  near $\varphi = 0$, and the `LogExpRoundTrip` small-angle case at $10^{-5}$ caught the
  first version that tested only the sine.

  Using $R + I$ itself, the form usually quoted, is wrong here: its columns also contain
  $\sin\varphi\,(u \times e_j)$, perpendicular to $u$, so the extracted axis is off by
  $O(\sin\varphi)$, which at $\varphi = \pi - 10^{-4}$ is $10^{-4}$. The first implementation
  did exactly this and the `ExpLogRoundTrip` near-$\pi$ cases failed with round-trip errors
  of $10^{-4}$, hence the symmetric-part form above.

Invariants: $\mathrm{Exp}(\mathrm{Log}(R)) = R$ for all $R$, and
$\mathrm{Log}(\mathrm{Exp}(\theta)) = \theta$ for $\|\theta\| < \pi$.

### Left and right Jacobians

A perturbation $\delta$ of the tangent vector is not the same as a perturbation of the
rotation. The right Jacobian $J_r$ is defined by

```math
\mathrm{Exp}(\theta + \delta) \approx \mathrm{Exp}(\theta)\,\mathrm{Exp}(J_r(\theta)\,\delta),
```

and the left Jacobian $J_l$ by $\mathrm{Exp}(\theta + \delta) \approx
\mathrm{Exp}(J_l(\theta)\,\delta)\,\mathrm{Exp}(\theta)$. Differentiating
$\mathrm{Exp}(s\theta)$ gives the integral forms

```math
J_l(\theta) = \int_0^1 \mathrm{Exp}(s\theta)\, ds, \qquad
J_r(\theta) = \int_0^1 \mathrm{Exp}(-s\theta)\, ds .
```

Integrating Rodrigues term by term, with $\int_0^1 \frac{\sin s\varphi}{\varphi} ds =
\frac{1 - \cos\varphi}{\varphi^2}$ and $\int_0^1 \frac{1 - \cos s\varphi}{\varphi^2} ds =
\frac{\varphi - \sin\varphi}{\varphi^3}$:

```math
J_l(\theta) = I + \frac{1-\cos\varphi}{\varphi^2}[\theta]_\times
  + \frac{\varphi - \sin\varphi}{\varphi^3}[\theta]_\times^2, \qquad
J_r(\theta) = I - \frac{1-\cos\varphi}{\varphi^2}[\theta]_\times
  + \frac{\varphi - \sin\varphi}{\varphi^3}[\theta]_\times^2 .
```

Relations that the tests check: $J_r(\theta) = J_l(-\theta) = J_l(\theta)^\top$ and
$J_l(\theta) = \mathrm{Exp}(\theta)\,J_r(\theta)$.

The inverses have closed forms too (verify by multiplying out with the cubic identity for
$[\theta]_\times$):

```math
J_r^{-1}(\theta) = I + \tfrac12[\theta]_\times
  + \left(\frac{1}{\varphi^2} - \frac{1 + \cos\varphi}{2\varphi\sin\varphi}\right)[\theta]_\times^2,
\qquad
J_l^{-1}(\theta) = I - \tfrac12[\theta]_\times
  + \left(\frac{1}{\varphi^2} - \frac{1 + \cos\varphi}{2\varphi\sin\varphi}\right)[\theta]_\times^2 .
```

Small-angle series used below $\varphi = 10^{-6}$:
$J_r \approx I - \tfrac12[\theta]_\times + \tfrac16[\theta]_\times^2$,
$J_r^{-1} \approx I + \tfrac12[\theta]_\times + \tfrac1{12}[\theta]_\times^2$ (and $J_l$ with
the sign of the linear term flipped). $J_r^{-1}$ is singular at $\varphi = 2\pi$, which
$\mathrm{Log}$ never returns; callers that add tangent vectors must keep $\|\theta\| < \pi$.

The inverse Jacobian is what makes $\boxminus$ differentiable:

```math
\mathrm{Log}\big(\mathrm{Exp}(\theta)\,\mathrm{Exp}(\delta)\big) \approx \theta + J_r^{-1}(\theta)\,\delta .
```

### Adjoint on SO(3)

Conjugation moves a perturbation across a rotation:

```math
R\,\mathrm{Exp}(\delta)\,R^\top = \mathrm{Exp}(R\delta)
\quad\Longleftrightarrow\quad
\mathrm{Exp}(\delta)\,R = R\,\mathrm{Exp}(R^\top \delta).
```

This follows from $[R\delta]_\times = R[\delta]_\times R^\top$ applied to each term of the
series. The adjoint of $SO(3)$ is therefore $R$ itself.

### SE(3)

A pose is the pair $T = (R, t)$ with the composition and inverse of doc 00:

```math
T_1 T_2 = (R_1 R_2,\; R_1 t_2 + t_1), \qquad
T^{-1} = (R^\top,\; -R^\top t), \qquad
T\,p = R p + t .
```

**Exponential.** For a constant twist $\xi = (\theta, \rho)$ the pose $T(s)$ solving
$\dot T = T\,\hat\xi$, $T(0) = I$, with $\hat\xi = \begin{bmatrix}[\theta]_\times & \rho\\0&0\end{bmatrix}$,
has rotation $\mathrm{Exp}(s\theta)$ and translation $\dot t = R(s)\rho$, so

```math
\mathrm{Exp}(\xi) = \Big(\mathrm{Exp}(\theta),\; \int_0^1 \mathrm{Exp}(s\theta)\,\rho\, ds\Big)
                  = \big(\mathrm{Exp}(\theta),\; J_l(\theta)\,\rho\big).
```

The same left Jacobian appears, which is why it was derived in integral form.

**Logarithm.** Invert term by term: $\theta = \mathrm{Log}(R)$, $\rho = J_l^{-1}(\theta)\,t$.

**Adjoint.** $T\,\mathrm{Exp}(\xi) = \mathrm{Exp}(\mathrm{Ad}_T\,\xi)\,T$ with, in the
$(\theta, \rho)$ ordering,

```math
\mathrm{Ad}_T = \begin{bmatrix} R & 0 \\ [t]_\times R & R \end{bmatrix} .
```

Derivation: $T \hat\xi T^{-1}$ has rotation block $R[\theta]_\times R^\top = [R\theta]_\times$
and translation block $R\rho - R[\theta]_\times R^\top t = R\rho + [t]_\times R\theta$.
The adjoint is what converts a covariance expressed as a perturbation of $T_{WL}$ into one
of $T_{WI}$ (doc 04, doc 05): if $T_{WI} = T_{WL} T_{LI}$ and $T_{WL} \boxplus \xi_L$, then
$T_{WI} \boxplus \mathrm{Ad}_{T_{IL}}\,\xi_L$ (from $T_{WL}\mathrm{Exp}(\xi_L)T_{LI}
= T_{WI}\,T_{IL}\mathrm{Exp}(\xi_L)T_{IL}^{-1}$).

**Jacobian of a transformed point.** For registration (doc 03) the needed derivative is of
$p_W = T\,p$ with respect to a right perturbation of $T$. With
$\mathrm{Exp}(\xi) \approx I + \hat\xi$,

```math
(T\,\mathrm{Exp}(\xi))\,p \approx R\big(p + [\theta]_\times p + \rho\big) + t
  = T p + R\big(-[p]_\times \theta + \rho\big),
```

so

```math
\frac{\partial (T p)}{\partial \xi} = \begin{bmatrix} -R[p]_\times & R \end{bmatrix} \in \mathbb{R}^{3\times 6}.
```

### Composition of the ground truth with the extrinsic

The dataset gives $T_{WI}(t)$ and the calibration gives $T_{IL}$. The pose of the LiDAR
frame, which is what scan registration estimates, is

```math
T_{WL}(t) = T_{WI}(t)\,T_{IL}, \qquad
t_{WL} = R_{WI}\,t_{IL} + t_{WI}, \qquad R_{WL} = R_{WI} R_{IL} .
```

Going the other way, an estimated $T_{WL}$ is reported in the ground-truth frame as
$T_{WI} = T_{WL}\,T_{IL}^{-1}$. Both directions are used: `gt_to_tum.py` produces
`gt_lidar_frame.tum` with the first, and the odometry writes IMU-frame trajectories with the
second so evo compares like with like.

Why the second direction is not optional: evo's ATE aligns the two trajectories with one
global $T \mapsto S\,T$ (left multiplication), which absorbs a constant frame change on the
left but not the constant $T_{IL}$ on the right. On exp14 the aligned ATE between
`gt.tum` and `gt_lidar_frame.tum` is only 8.7 mm RMSE (the lever arm is 5.6 cm and mostly
rotates with the body), so a forgotten extrinsic would be nearly invisible in ATE. RPE is
different: the relative motion $\Delta_L = T_{IL}^{-1}\,\Delta_I\,T_{IL}$ is expressed in the
body frame, and with $R_{IL}$ a rotation by $\pi$ the translation part of
$\Delta_I^{-1}\Delta_L$ is $R_{IL}^\top t - t$, up to twice the step. Measured: 1.58 m RMSE
RPE over 1 m steps between the two files. Any RPE number is therefore only meaningful when
the estimate has been brought into frame $I$ first.

## Worked example

With the Hilti extrinsic $t_{IL} = (-0.001, -0.00855, 0.055)$ m and an IMU pose with
$R_{WI} = I$ and $t_{WI} = (10, -2, 0.5)$ m, the LiDAR origin in the world is
$(9.999, -2.00855, 0.555)$ m: 5.5 cm above the IMU along $z_W$, since $z_I = z_W$ here.
Rotating the IMU by $\pi/2$ about $z_W$ instead moves the offset to
$R_{WI} t_{IL} = (0.00855, -0.001, 0.055)$, and the LiDAR origin to
$(10.00855, -2.001, 0.555)$ m. A 6-DoF ground-truth error of this size (about 1 cm in the
plane) would appear if the composition were skipped, comparable to the best ATE on the
challenge leaderboard, which is why the frame is transformed rather than ignored.

## Spec

### Signatures

All in namespace `ranger_lio`, header-only declarations in `include/ranger_lio/so3.hpp` and
`se3.hpp`, definitions in `src/so3.cpp` and `src/se3.cpp`. `Vector6d` and `Matrix6d` are
`Eigen::Matrix<double,6,1>` and `Eigen::Matrix<double,6,6>`.

```cpp
namespace so3 {
Eigen::Matrix3d hat(const Eigen::Vector3d& a);
Eigen::Vector3d vee(const Eigen::Matrix3d& A);          // requires A skew-symmetric
Eigen::Matrix3d Exp(const Eigen::Vector3d& theta);
Eigen::Vector3d Log(const Eigen::Matrix3d& R);          // returns |theta| <= pi
Eigen::Matrix3d Jr(const Eigen::Vector3d& theta);
Eigen::Matrix3d Jl(const Eigen::Vector3d& theta);
Eigen::Matrix3d JrInv(const Eigen::Vector3d& theta);
Eigen::Matrix3d JlInv(const Eigen::Vector3d& theta);
}  // namespace so3

struct SE3 {
  Eigen::Matrix3d R;  Eigen::Vector3d t;                 // identity by default
  static SE3 fromQuaternionXYZW(double qx, double qy, double qz, double qw, const Eigen::Vector3d& t);
  Eigen::Vector4d quaternionXYZW() const;
  SE3 operator*(const SE3& other) const;                 // composition T_A_C = T_A_B * T_B_C
  Eigen::Vector3d operator*(const Eigen::Vector3d& p) const;  // action R p + t
  SE3 inverse() const;
  static SE3 Exp(const Vector6d& xi);                    // xi = (theta, rho)
  Vector6d Log() const;
  Matrix6d Adj() const;
  Eigen::Matrix<double, 3, 6> actionJacobian(const Eigen::Vector3d& p) const;  // d(T p)/d xi
  Eigen::Matrix4d matrix() const;
};
```

### Invariants

1. `vee(hat(a)) == a`; `hat(a) * b == a.cross(b)`.
2. `Exp(Log(R)) == R` for every rotation, including angles within $10^{-4}$ of $\pi$.
3. `Log(Exp(theta)) == theta` for $\|\theta\| < \pi - 10^{-3}$; small angles down to $10^{-9}$ included.
4. `Exp(theta)` is orthonormal with determinant $+1$.
5. `Jr(theta) == Jl(-theta) == Jl(theta).transpose()` and `Jl(theta) == Exp(theta) * Jr(theta)`.
6. `Jr(theta) * JrInv(theta) == I` and `Jl(theta) * JlInv(theta) == I` for $\|\theta\| < \pi$.
7. `Jr` matches the central-difference Jacobian of $\delta \mapsto \mathrm{Log}(\mathrm{Exp}(\theta)^\top \mathrm{Exp}(\theta + \delta))$ at $\delta = 0$.
8. `JrInv` matches the central-difference Jacobian of $\delta \mapsto \mathrm{Log}(\mathrm{Exp}(\theta)\,\mathrm{Exp}(\delta))$ at $\delta = 0$.
9. `R * Exp(d) * R^T == Exp(R d)`.
10. `T * T.inverse()` is the identity; `(T1 * T2) * p == T1 * (T2 * p)`.
11. `SE3::Exp(T.Log()) == T` and `SE3::Exp(xi).Log() == xi` for $\|\theta\| < \pi - 10^{-3}$.
12. `T * SE3::Exp(xi) == SE3::Exp(T.Adj() * xi) * T`.
13. `actionJacobian(p)` matches the central-difference Jacobian of $\xi \mapsto (T\,\mathrm{Exp}(\xi))\,p$ at $\xi = 0$.
14. `fromQuaternionXYZW` of the Hilti extrinsic maps $z_L$ to $-z_I$ and $x_L$ to $-y_I$; `quaternionXYZW()` round-trips up to sign.
15. `T_W_I * T_I_L` has translation `R_W_I * t_I_L + t_W_I`.
